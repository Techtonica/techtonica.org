# Techtonica.org Style Guidelines

This document outlines the visual and structural conventions used across the Techtonica website to ensure consistency.

## Components

### Footer Icons
Icons used in the footer must adhere to the following standards:
- **Sizing**: Icons should maintain a consistent height and width (standardized to 24px unless specified otherwise).
- **Color Palette**: Use the primary brand colors or a muted grayscale for secondary links to maintain visual hierarchy.
- **Spacing**: A minimum gap of `1rem` (16px) must be maintained between adjacent icons.
- **Interactivity**: All icons must have a `:hover` state that provides visual feedback (e.g., slight opacity change or color shift).

### Sponsor Table
The sponsor table is used to showcase organizational partners and must follow these rules:
- **Layout**: Use a responsive grid or table layout that collapses gracefully on mobile devices.
- **Alignment**: Logos must be centered within their respective cells.
- **Scaling**: Logos should be scaled to fit the container while maintaining their original aspect ratio.
- **Tiering**: Sponsors should be grouped by tier (e.g., Platinum, Gold, Silver) with clear visual separation or heading labels for each section.
- **Linking**: Each sponsor logo must be wrapped in an anchor tag leading to the sponsor's official website, opening in a new tab (`target="_blank"`).

## General Conventions
- **Typography**: Follow the established font-family hierarchy defined in the global CSS.
- **Spacing**: Use a consistent spacing scale (multiples of 4px or 8px).
