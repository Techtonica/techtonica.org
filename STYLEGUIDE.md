# Techtonica Style Guide

This document outlines the visual and structural conventions used across the techtonica.org website to ensure consistency.

## Form Components

### Application Form Inputs
- **Text Inputs**: Should maintain a consistent border-radius and focus state. Focus states must use the primary brand color to ensure accessibility.
- **Validation States**: Error states should be indicated by a red border and a supporting text message below the input.

### Pagination
- **Style**: Pagination controls should be centered.
- **Active State**: The current page indicator must be visually distinct (e.g., bold background or primary color) to provide clear orientation to the user.
- **Transitions**: Smooth transitions between pages to prevent jarring layout shifts.

### Icon Bubbles & Modals
- **Hover Effects**: Icon bubbles (info tips) must trigger a modal or tooltip on hover.
- **Modal Styling**: 
    - Background: Semi-transparent overlay or solid neutral background.
    - Animation: Fade-in or slight slide-up effect.
    - Positioning: Must be relative to the trigger icon to ensure the user maintains context.

## General Conventions
- **Spacing**: Use a consistent spacing scale (e.g., multiples of 4px or 8px).
- **Typography**: Follow the established hierarchy for headings (H1-H6) and body text.
