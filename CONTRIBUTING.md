# Contributing to Techtonica

Thank you for your interest in helping us improve Techtonica! 

## General Contributions
Please follow the standard PR process for code and content changes within the repository.

## Contributing to the Wiki
We maintain a Wiki to provide documentation and guides. However, please note that **the GitHub Wiki is separate from the main website**. 

### How the Wiki Process Works:
1. **Direct Edits:** You can edit Wiki pages directly on GitHub. These changes are immediate on the Wiki pages but **do not** automatically update the main website.
2. **Website Integration:** If you believe a Wiki page should be promoted to a permanent part of the main website:
   - Create a Pull Request in this repository.
   - Add the content to the appropriate directory (usually under `/docs` or the relevant content folder).
   - Reference the Wiki page in your PR description.
3. **Review Process:** All website changes undergo a peer review process to ensure consistency in styling and accuracy.

### Tips for Wiki Contributors:
- Use clear headings.
- Link to other relevant Wiki pages.
- If you are documenting a new process, please notify a maintainer so we can evaluate if it should be moved to the main site.

---
*For any questions regarding the documentation process, please open an issue or reach out to the maintainers.*
